# Mode5HDMA

Mode 5 hi-res (512px) background with font-based text rendering and an HDMA
effect driven by a runtime-assembled IRQ handler. Background data is converted
by `ConvertImageMode5.py`; the font is generated by `generate_font.py`.

## Building

From this directory (see ../README.md for one-time toolchain setup):

    make COMPILER=cc65
    make COMPILER=calypsi
    make COMPILER=llvm-mos
    make clean

Output ROM: `build/mainBankZero_<compiler>.smc`.

## Status

Builds with calypsi and vbcc65816. cc65 and tcc816 overflow the fixed ROM bank;
llvm-mos crashes the compiler frontend on this demo's larger data set.
